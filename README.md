# T&T Tử Vi Đẩu Số App — Bản đóng gói Windows (Tauri)

Xem hướng dẫn build chi tiết tại [`HUONG-DAN-BUILD-EXE.md`](./HUONG-DAN-BUILD-EXE.md).

Ứng dụng gốc (file HTML tự chứa, chạy trực tiếp trong trình duyệt) nằm tại `dist/index.html` — đây là bản đang chạy trên bản web (https://tranthanhnd.github.io/TVT-TU-VI-DAU-SO-APP/), gồm: tính lá số Tử Vi Đẩu Số, xem vận hạn năm/tháng, luận giải chi tiết 10 mục qua Gemini API (cần người dùng tự nhập API Key riêng).

Lưu ý: repo này CÔNG KHAI (public) để build .exe miễn phí không giới hạn qua GitHub Actions. App không lưu bất kỳ API Key nào trong code — Key chỉ lưu cục bộ trên máy người dùng.
